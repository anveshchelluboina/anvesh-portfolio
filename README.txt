# Anvesh Chelluboina — portfolio refresh

## What is included
- `index.html` — new responsive portfolio homepage and travel gallery
- `slides.html` — six-slide visual profile, keyboard/touch navigable
- `flapboard.css` — shared responsive design system and styling
- `flapboard.js` — gallery filters, lazy-loaded photos, lightbox and slide navigation
- `assets/photos/` — 43 photos extracted from the supplied `Pics.pdf`

## Update GitHub Pages
1. Download and unzip `Anvesh_Portfolio_Updated.zip`.
2. In your GitHub repository, upload/replace `index.html`, `slides.html`, `flapboard.css`, and `flapboard.js` in the repository's root folder.
3. Upload the complete `assets` folder as well, keeping all 43 images inside `assets/photos/`.
4. Commit the changes. Wait a minute or two, then refresh your GitHub Pages website.
5. Open `index.html` and test the photo filters, “Show more photos”, image lightbox, and `slides.html`.

Keep the folder names and file names exactly as provided. The site uses Google Fonts; if those are unavailable, it falls back to system fonts. All photo files are local, so no external image host is needed.
